## How shortcuts work in Musset

Every command has one name and one shortcut, shown the same way in the menus, in tooltips and in the [command bar](/guide/command-bar/) ([[⌘K]]). If you forget one, press [[⌘K]] and type the command's name: its shortcut is beside it.

These are the shortcuts of the default **Mac / Word** keyboard mode. They also work in WordStar, vi and Emacs modes, because Command always stays Musset's. See [keyboard modes](/guide/keyboard-modes/).
